# QR Code Generator

一个极简、专业、开源的二维码生成工具，纯前端实现，无需后端。

**在线体验**: 直接打开 `index.html` 即可使用。

## 功能特性

- **多类型支持**: 网址、文本、Wi-Fi、邮箱、电话
- **自定义样式**: 尺寸、容错级别、前景色、背景色
- **多格式导出**: PNG / SVG 下载，一键复制到剪贴板
- **隐私安全**: 所有数据本地处理，不上传任何信息
- **响应式设计**: 支持手机、平板、桌面端

## 部署到 GitHub Pages

1. 创建 GitHub 仓库
2. 将 `index.html` 推送到仓库
3. 在仓库 Settings → Pages 中选择分支发布
4. 访问 `https://<username>.github.io/<repo>/`

## 技术栈

- Tailwind CSS
- QRCode.js
- 纯 HTML/CSS/JS，零依赖构建
